Privacy information

Provisional information about data and technologies used by the static Consola Abierta website.

Current site behaviour

Consola Abierta currently serves static editorial pages. It has no user registration, newsletter subscription, contact form, advertising platform or first-party analytics. The on-page search runs in the visitor browser against a static JSON index; search terms are not submitted to the publisher.

Hosting and technical access data

The site is published through GitHub Pages. The hosting provider may process technical connection data to deliver, secure and maintain the service under its own terms and privacy documentation.
