Aviso de seguridad

El laboratorio de tempdb requiere una instancia desechable y aislada. Nunca ejecutes sus scripts en producción o en una instancia compartida. Lee siempre el README antes de ejecutar cualquier paquete.

Cómo interpretamos la evidencia

Diferenciamos entre experimentos numéricos, simulaciones, análisis de trazas y reproducciones sobre software real. Un resultado sintético no se presenta como una medición de producción. Revisa siempre el README antes de ejecutar un laboratorio.

Coste de los laboratorios

Los paquetes no requieren servicios cloud, APIs de pago ni suscripciones. Algunos utilizan dependencias gratuitas como PyTorch; otros funcionan con la biblioteca estándar de Python. Los requisitos específicos aparecen en cada ficha.
